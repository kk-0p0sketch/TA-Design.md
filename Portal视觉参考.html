推荐 Noto Sans SC。它的笔画收束利落，小字号里的“版”“差”仍容易辨认。用同一套字库服务 Windows 和 Mac，工具名与长列表的字重更容易保持一致。

另一种选择是跟随系统。Apple 设备优先苹方-简，Windows 优先 Microsoft YaHei UI，再回退到 Microsoft YaHei。该方案直接使用设备字体。两侧拉丁字母与数字的字形保持一致。

      用 Vercel 的组件尺寸控制密度

      取 Geist Button 和 Input 的三档桌面高度。同一排的输入与按钮选同档：32 px 给紧凑筛选，36 px 给常规表单，40 px 给需要突出的操作。Portal 主搜索可将输入框和按钮各自放大到 48 px，两者之间留 8 px。
